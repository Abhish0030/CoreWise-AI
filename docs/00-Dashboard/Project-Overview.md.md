# 🚀 CoreWise AI

> The Right Workload. The Right Processor.

## 📌 Project Overview

**Full Title:** Machine Learning-Based CPU-GPU Workload Prediction and Resource Optimization Using Agentic AI.

**Domain:** Computer Organization and Architecture, Machine Learning, Agentic AI.

**Project Status:** In Development

**Team Size:** 5 Members

## 🎯 Project Objective

To develop an intelligent system that analyzes computational workloads, predicts CPU and GPU execution times, and recommends the more suitable processing unit using machine learning and Agentic AI.

# M7 security review

This is an implementation review with executable tests, not an independent penetration test or security certification. M0–M6 controls were preserved. No production credentials, deployment or destructive database restore were assumed.

## Reviewed boundaries

- **Authentication/session/cookies:** Argon2id, library-signed HttpOnly cookies, PostgreSQL session store, absolute expiry, regeneration and logout invalidation remain. Production Secure/__Host-/SameSite=Lax settings and trusted-proxy behavior remain tested in configuration tests; live TLS deployment is not claimed.
- **CSRF/origins/CORS:** Session-bound synchronizer header on every ordinary write, including auth/preview/SSE. Existing exact Origin and Fetch Metadata controls remain. Browser API calls use the Next `/api` rewrite; no permissive browser CORS was added. Private FastAPI remains bearer-authenticated without browser CORS credentials.
- **Authorization:** Personal queries include owner IDs resolved from the session; foreign records return generic 404. Report snapshots cannot resolve foreign sources. Public overview fetches private evidence only after authenticated identity and uses owner-specific query keys. Settings/reports require server-side sessions. Runner-only sessions cannot access personal APIs.
- **Uploads:** Existing UTF-8 CSV byte/row/schema/provenance, finite-number, grouping and target validation remain; there is no report file upload or arbitrary pickle upload. Measured metadata remains uploader/runner-attested, not physical proof. Do not train supervised models on analytical/agent-generated labels.
- **Local runner:** One-time short-lived pairing, hashed revocable credentials/native vault, regenerated scoped sessions/CSRF, fixed allowlist, memory/size/deadline/OS lock, explicit execution and outbound-only transport remain. Reports do not start benchmarks. A valid paired runner can still lie; authentication is not hardware attestation.
- **Model/SHAP:** Trusted private UUID artifacts and exact-byte integrity, immutable model/dataset/prediction references, training-only backgrounds, grouped held-out evaluation and checked log-time additivity remain. Filesystem/registry write access is privileged; hashes are not signatures against a compromised storage administrator.
- **Agent/SSE:** Fixed authenticated callback, expiring session/CSRF-bound grants, per-owner sources, six-call/two-round/eight-iteration budgets, per-user database turn limits, provider/tool deadlines, size/context limits and cancellation remain. User/retrieved text is untrusted data, not system instructions. No SQL/shell/filesystem/network/write tool exists. Structured citations/cards come from stored Express evidence rather than model-authored URLs.
- **Logs/secrets:** Pino redacts Authorization/Cookie/CSRF/grant/Set-Cookie headers; provider exception bodies are not streamed. Known secrets and credential patterns are filtered from chat/tool/report strings. Public schemas exclude password/session/internal artifact paths. Filtering is best-effort, not a general DLP classifier; do not paste credentials into user content or enable unreviewed upstream tracing.
- **Reports:** Sanitized immutable JSON plus actual PDF/CSV bytes/checksums in PostgreSQL; later source edits/deletion cannot rewrite history. Account deletion cascades reports. User-visible snapshots/exports may contain private project/device metadata and need corresponding backup/retention access controls. Report deletion does not delete original evidence.

## Residual risks and release gates

Existing global/IP/auth and report-request limit stores are process-local. The documented reference topology uses one API instance; multiple replicas require a shared limiter before production. Database sessions and agent/report admission limits are already shared, but do not cover all IP abuse controls. Account recovery/email verification/MFA/account deletion UI remain outside implemented M1 capabilities. No claim of full WCAG certification, calibrated hardware ML accuracy, external provider quality, universal PDF script shaping or independent security audit is made.

Operator-controlled provider/service URLs and secrets must remain private; HTTPS is required for remote providers and untrusted service networks. Configure the actual proxy/cookie chain, firewall, database least privilege, artifact permissions, process memory/CPU limits, backups, retention, monitoring and dependency review before exposure. The production checker validates a reference environment shape only and prints issue names without credentials. Keep runtime/build dependencies pinned and update them through tested release work.

Run typecheck/lint/build, full PostgreSQL API tests, Python ML/agent/runner tests and Ruff, and real browser regressions. API and browser suites must not overlap the shared durable worker queue. Deterministic LLM mocks are test-only; do not describe their success as live provider verification. Actual test counts, graphical/PDF review and remaining external integrations are recorded in STATUS.
